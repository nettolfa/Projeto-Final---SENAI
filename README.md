# FEMM Livraria Online

Projeto final do curso do SENAI, feito em grupo: uma livraria online com catálogo de livros, página de cada livro e login de usuário.

**Ver online:** https://projeto-final-senai-smqj.vercel.app/

## Estrutura
- `front_End/`: páginas em HTML, CSS e JavaScript (início, livro e login), com carrossel feito com Glider.js
- `back_End/`: API em Node.js com Express, ligada a um banco MySQL (`banco.sql`)

## Como rodar o back-end
```bash
cd back_End
npm install
node app.js
```
Antes, crie o banco com o script `banco.sql` no MySQL.

## Tecnologias
HTML, CSS, JavaScript, Node.js, Express e MySQL. Front-end publicado na Vercel.
